# お知らせの編集方法（お客様向け）

お知らせはサイト上の管理画面から更新します。コードや Sanity Studio を開く必要はありません。

## 手順

1. 管理者から共有された管理画面の URL を開く  
   例: `https://（サイトのドメイン）/admin`
2. パスワードを入力して **ログイン**
3. **＋ 新しいお知らせ** で追加、または一覧の **編集** / **削除**
4. **日付**・**タイトル**を入れる（リンクは任意。例: `/downloads`）
5. **保存する** を押す
6. 数分待つ（サイトが自動で更新されます）

## メモ

- 公開後、トップの「お知らせ」と `/news` の一覧の両方に反映されます
- すぐ変わらない場合は少し待ってからページを再読み込みしてください
- 管理 URL やパスワードが分からない場合は、サイト管理者に連絡してください
