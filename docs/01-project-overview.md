# Project Overview

## Project
Urondo website planning package

## Goal
Build a clean, content-first website from customer-provided documents.

## Phase-One Rule
Keep customer content unchanged in wording and meaning.

Allowed in phase one:
- Reformat content for web readability
- Add headings and layout structure
- Convert repeated information into tables, cards, and sections
- Add navigation and calls to action

Not allowed in phase one:
- Rewrite customer claims
- Change pricing, schedules, or instructions
- Remove content without approval

## Source Material
The current project folder contains the customer source files:
- `.docx` content documents for pages
- `.pdf` and `.xlsx` downloadable application forms

These files are the source of truth for phase-one implementation.

## Recommended Output
This project should be built as a simple static website with:
- Homepage
- About page
- Treatment pages
- Class/course pages
- Access page
- Company page
- Contact page
- Download page
- Privacy policy

## Recommended Tech Direction
Use Astro for a simple, maintainable static site build with reusable layouts and strong SEO support.
